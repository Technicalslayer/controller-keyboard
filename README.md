# Accessibility tool to use a controller as a keyboard and mouse.
Uses a daisy wheel for speedy keyboard inputs and a gyro configuration for direct mouse control.
Made with Godot 4.5 using GDExtension https://github.com/Technicalslayer/godot-input-emulation to allow emulated OS keystrokes and gyroscope support.
Work in progress, but anyone's welcome to use what's here for their own projects.

With Godot's 4.7 controller improvements, the GDExtension has redundant features as the engine's native support is superior.
Currently only works width Windows, and tested only on Windows 10.
